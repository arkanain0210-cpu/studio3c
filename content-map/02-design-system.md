# 02 · 디자인 시스템

요약하면 **"잉크 한 색 + 강조 한 색, 서체 한 종, 아주 큰 글자와 아주 작은 글자"**다.
장식(그림자·그라데이션·둥근 모서리·아이콘)은 거의 없고 대비와 여백으로만 위계를 만든다.

## 1. 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#ECEEF4` | 밝은 바탕 (푸른 기가 도는 회색) |
| `--ink` | `#131419` | 본문·제목·선 |
| `--mute` | `#7A7D8B` | 보조 글, 라벨 |
| `--faint` | `#B7BAC8` | 지나간 요소, 흐린 선 |
| `--line` | `#C9CCD8` | 구분선 |
| `--blue` | `#F2641E` | **강조색. 이름은 blue인데 값은 주황이다** (색을 바꾸고 변수명은 그대로 둔 흔적) |
| `--dark` | `#101116` | 어두운 바탕 |
| `--dark2` | `#1A1B22` | 어두운 바탕 위 면 |
| `--dmute` | `#8D91A3` | 어두운 바탕 위 보조 글 |

파생색(변수 없이 직접 씀): 어두운 면의 구분선 `#2A2C37`, 테두리 `#3A3D4B`, 어두운 배경 위 강조 `#FF9A62`, 본문 회색 `#4C4F5C`.

**분류 색 4종** — 타임라인에서만 등장한다.

| 의미 | 색 |
|---|---|
| 창의적 B롤 | `#F2641E` 주황 |
| 일상 B롤 | `#2F9E6A` 초록 |
| 연출 B롤 | `#8B5CF6` 보라 |
| 일반 B롤 | `#7A5A45` 갈색 |

**구간 색 6종** — 대본 100 막대. 색상환이 아니라 **명도 단계**로 구분한다:
훅 = 흰색 + 주황 테두리, 빌드 = 잉크, 트위스트 = 회색, 보상 = 주황, CTA = 연주황 `#FFB48A`, 아웃트로 = 연회색.

규칙: 밝은 면이 기본이고(17개 구간 중 11개) 어두운 면은 타임라인·실험실·분석·결론·라이브러리처럼 **집중해서 볼 대목**에만 쓴다. 강조색은 한 화면에 한두 군데만 쓴다.

## 2. 타이포그래피

- 서체: Pretendard 한 종 (400·500·600·700). 숫자·코드만 `ui-monospace`.
- 기본: `16px / 1.5`, 자간 `-0.03em`.
- 원칙: **글자가 커질수록 자간을 더 좁힌다.**

| 단계 | 크기 | 굵기 | 자간 | 행간 | 예 |
|---|---|---|---|---|---|
| 초대형 | `min(11.5vw, 17vh)` | 700 | -0.075em | 0.98 | 히어로 제목 |
| 대형 | `min(10.5vw, 20vh)` | 700 | -0.08em | 0.9 | 가로 패널 제목 |
| 섹션 제목 | `min(7.2vw, 110px)` | 700 | -0.075em | 1.02 | 일반 섹션 h2 |
| 읽는 큰 글 | `min(4.7vw, 8vh)` | 700 | -0.07em | 1.3 | 분석 문장 |
| 중제목 | `min(3.6vw, 52px)` | 700 | -0.065em | 1.2 | 카드 제목, 인용 |
| 소제목 | 22–24px | 600 | -0.05em | 1.3 | 설명 패널 |
| 본문 | 14–15px | 400 | -0.03em | 1.75 | 설명 |
| 라벨(eyebrow) | 11px | 500 | **+0.12em**, 대문자 | 1.8 | `02 / FORMAT` |

- 큰 글자는 전부 `min(vw, vh)` — 가로가 좁든 세로가 낮든 넘치지 않는다.
- 한글 줄바꿈은 `word-break: keep-all`로 어절 단위.
- 라벨만 자간을 넓혀(+0.12em) 본문과 결이 반대가 되게 한다. 이 대비가 화면의 "편집 디자인" 느낌을 만든다.

## 3. 레이아웃

- **좌우 여백 `3.2vw`** (모바일 `5vw`). 거의 모든 `left/right/padding`이 이 값이다.
- **22% 라벨 열**: 일반 섹션은 `grid-template-columns: 22% 1fr`. 왼쪽 22%에 작은 라벨, 오른쪽에 큰 제목.
  본문 블록도 `margin-left: 22%`로 같은 선에 맞춘다. 모바일에서는 0으로.
- **고정 장면의 네 귀퉁이 배치**:
  - 좌상단 — 장면 라벨 (`top: 96px`)
  - 좌하단 — 단계 번호 또는 설명 (`bottom: 9vh`)
  - 우하단 — 설명 패널 (`width: min(360px, 32vw)`)
  - 가운데 — 주인공 그래픽
- 세로 간격은 `vh`로 준다 (`padding: 22vh … 14vh`, `margin-bottom: 10vh`).
- 중단점: 900px(태블릿), 759px(모바일). JS의 모바일 판정은 `innerWidth < 760`.

## 4. 컴포넌트

| 이름 | 클래스 | 모양 |
|---|---|---|
| 상단 바 | `.top` | 흰 글자 + `mix-blend-mode: difference` → 어떤 배경 위에서도 반전돼 보인다. 진행선 2px |
| 장면 라벨 | `.scene-label` | `NN / 영문` 작은 글 + 그 아래 한글 한 줄 |
| 섹션 머리 | `.head` | 22% 라벨 + 초대형 제목 + 보조 문장 |
| 단계 그리드 | `.steps` | 위쪽 굵은 선 1px, 칸 사이 세로선, `01` 번호 → 제목 → 설명 |
| 알약 버튼 | `.ref-inline button` | 테두리 1px, 호버 시 잉크로 채움. 끝에 `↗` |
| 토글 칩 | `.choice button` | `aria-pressed="true"`면 반전 |
| 표 | `.cases` | 5열 그리드, 가로선만, 셀 글자가 큼(최대 34px) |
| 카드 | `.card` | 9:16 썸네일(채도 0.6 → 호버 시 원색 + 확대), 제목, 메타 한 줄 |
| 구간 카드 | `.clip` | 9:13 영상, 좌상단 시각, 우하단 "소리 켜기" |
| 구간 막대 | `.s1-bar` | 높이 14px, 구간별 색 조각, 조각 사이 2px 틈 |
| 아코디언 줄 | `.s1-row` | 번호 · 제목 · 막대 · `+` (열리면 45° 회전) |
| 타임라인 | `.tl` | 눈금자 · 구간 괄호 · 레인 4줄 · 재생선(흰색 2px + 글로우) |
| 모니터 | `.mon` | 9:16 영상 + 상단 종류 라벨 + 타임코드 |
| 설명 패널 | `.ladder-note` 등 | 내용이 바뀔 때 0.22초 사라졌다 나타남 |
| 팝업 | `dialog` | `min(1320px, 94vw) × min(860px, 92vh)`, 배경 90% 검정 |

**모서리**: 초기에는 12–18px 둥근 모서리였으나 마지막에 `.clip, .card .th, .choice button { border-radius: 0 }`으로 대부분 직각이 됐다.
남은 둥근 모서리는 히어로 영상(18px → 0으로 변함), 층 분해의 판(18px), 팝업(16px) 정도다.

## 5. 모션

| 종류 | 값 |
|---|---|
| 기본 이징 | `cubic-bezier(.16, 1, .3, 1)` — 빠르게 나와 길게 감속 |
| 보조 이징 | `cubic-bezier(.2, .7, .2, 1)` |
| 등장 (`.rv`) | 아래 40px에서, opacity 0.9s + transform 1.1s |
| 순차 등장 (`.rv2`) | 아래 26px에서, 항목당 0.06s 지연(8개 주기) |
| 제목 줄 마스크 | 줄을 `overflow: hidden`으로 감싸고 안쪽을 `translateY(112%)` → 0, 1.25s, 줄당 0.1s 지연 |
| 라벨 등장 | `blur(8px)` + 12px → 선명 |
| 내용 교체 | opacity 0.45s (필요 시 `blur(10px)` 동반) |
| 호버 | 0.3s 색 전환, 썸네일 0.8s 확대 |

스크롤 장면 안에서는 CSS 전환을 쓰지 않고 JS가 값을 직접 넣는다(→ [03](03-scroll-engine.md)).
**"나타날 때 흐림(blur)에서 선명으로"**가 이 페이지 전체의 공통 어휘다.

## 6. 내 것으로 바꿀 때

톤을 바꾸는 데 필요한 손잡이는 4개뿐이다.

1. `--bg` / `--dark` — 바탕의 온도 (원본: 차가운 회색)
2. 강조색 1개
3. 서체 1종
4. 모서리 반경 (0이면 편집 디자인, 12px 이상이면 앱 느낌)

스타터는 일부러 다른 값(따뜻한 바탕 `#F1EFEA`, 파란 강조 `#2B5BFF`)을 넣어 두었다. `:root`만 고치면 된다.
