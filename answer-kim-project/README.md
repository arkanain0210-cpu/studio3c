## 시작하기

1. 이 폴더(`answer-kim-project/`)를 원하는 위치에 두고, 그 안에서 Claude Code 세션을 엽니다. `CLAUDE.md`가 자동으로 맥락을 불러옵니다.
2. 처음이라면 `docs/01_overview.md`부터 읽으세요.
3. 대표님께 낸 제안서는 `docs/05_renewal_proposal.md`에 있습니다. 링크로 공유할 수 있는 원본은 Claude Docs 문서입니다.
